# калькулятор индивидуального расчёта

веб-инструмент, замена ручному пересчёту тарифов в экселе + ручному копипасту в файл.

живая версия: **https://polinachhhh.github.io/haccp-tracker-kp-calculator/**
(репозиторий публичный — код и формула цен видны всем; см. предупреждение внизу)

## как пользоваться
открыть ссылку выше в браузере (или `index.html` локально — двойной клик по файлу, интернет не нужен, `docx.js` лежит локально в `vendor/`).

1. вписать компанию клиента (необязательно)
2. отметить нужные модули (журналы / чек-листы / комплекс)
3. добавить точки для расчёта — кнопки 1/10/50 или своё число (можно несколько сразу — гибрид: 1 + фактическое число клиента, например)
4. вписать своё имя и телефон для подписи
5. проверить превью → «Создать в Google Docs» (готовая ссылка на документ) или «Скачать .docx»

документ — те же формулировки, что в старом шаблоне («индивидуальный расчёт», блок бонусов, подпись), но без риска затереть формулу или ошибиться в цифре.

## формула
```
цена = база(модуль) × месяцы × коэф_срока(месяцы) × коэф_точек(кол-во точек)
```
- базовые цены (1 точка, 1 месяц): журналы 3000 ₽, чек-листы 2450 ₽, комплекс 4360 ₽
- коэф. срока: 1 мес → 1, 3 мес → 0.8, 6 мес → 0.7, 12 мес → 0.6
- коэф. точек: 1 → 1, 2–4 → 0.85, 5–9 → 0.8, 10–49 → 0.7, 50+ → 0.6

**важно:** в исходной таблице границы коэф. точек были расплывчатые («2–5» и «5–10» пересекаются, «10+» и «50+» тоже). я разрешила это через убывающие пороги (см. `app.js`, функция `tochkiCoef`) — по построению совпадает с обоими проверочными примерами (10 точек → 0.7, 50 точек → 0.6). если реальная граница для 5 или 10 другая — поправить пороги в `app.js`.

сверено построчно с `Копия Индивидуальный расчет. Франшиза.md` — все цифры совпали, кроме комплекса на 10 точек/12 мес: там было 222 222 ₽ (похоже на опечатку), калькулятор даёт 219 744 ₽.

## настройка «Создать в Google Docs» (сделать один раз, только Полине)

кнопка шлёт данные в Google Apps Script, который создаёт документ в твоём Drive и открывает доступ по ссылке — менеджерам ничего настраивать не нужно.

1. зайти на **script.google.com** → «Новый проект»
2. стереть содержимое `Code.gs`, вставить туда весь код из [`google-apps-script/Code.gs`](google-apps-script/Code.gs) (в нём уже зашит логотип)
3. сохранить проект (можно назвать «HT — калькулятор КП»)
4. **Развернуть** (Deploy) → **Новое развёртывание** (New deployment)
   - тип: **Веб-приложение** (Web app)
   - «Execute as» → **Я** (свой аккаунт)
   - «Who has access» → **Все** (Anyone) — это нужно, чтобы калькулятор мог достучаться без твоего логина в браузере менеджера
   - нажать «Развернуть», разрешить доступ (Google покажет предупреждение «непроверенное приложение» — это нормально для собственного скрипта, жать «Advanced» → «Go to ... (unsafe)»)
5. скопировать выданный **URL веб-приложения** (заканчивается на `/exec`)
6. вставить его в [`app.js`](app.js) в строку `const GAS_WEBAPP_URL = "";` (между кавычками)
7. закоммитить и запушить — GitHub Pages обновится сам за минуту-две

документы создаются в твоём личном Drive (корневая папка), с доступом «у кого есть ссылка — просмотр». если понадобится складывать их в отдельную папку — можно добавить в `Code.gs` перемещение файла в конкретную папку по её ID (`DriveApp.getFolderById(...).addFile(file)`), скажи — допишу.

## если понадобится другой хостинг
это чистый статический html/js без сервера — можно перенести на любой статический хостинг (netlify, vercel и т.п.) без изменений в коде, просто скопировав папку.

## приватность репозитория
репозиторий на GitHub сейчас **публичный** — тарифная формула, коэффициенты и логотип доступны всем, у кого есть ссылка на репозиторий (или кто найдёт его через поиск/GitHub). если это нежелательно — попроси сделать репозиторий приватным (тогда GitHub Pages потребует платный тариф GitHub Pro/Team, либо нужен будет другой бесплатный хостинг для публичной части сайта при приватном коде).
